Minecraft Add-On Tool

パーティクルストリップメーカー ver3

動画から一定間隔でフレームを切り出し、縦1列に結合したPNGを書き出します。マイクラのパーティクルテクスチャ(アニメーション)にそのまま使えます。

1. 動画を読み込む

🎞️
動画ファイルをドラッグ&ドロップ
またはクリックして選択(mp4 / webm / mov 等)

2. 切り出し設定

3. プレビュー(不要なフレームは✕で除外)

4. 書き出し

5. SnowStorm用パラメータ

SnowStorm(particle-editor)のflipbook設定にそのまま入力してください。

デバッグログ

更新履歴

  • 「切り出し間隔(秒)」を「FPS」指定に変更
  • 書き出し後にSnowStorm用パラメータ(Texture Size / UV Start / UV Size / UV Step / Max Frame / FPS)を自動計算して表示
  • 「出力フレーム幅」指定でサイズを縮小できるオプションを追加
  • 出力画像がブラウザのCanvas上限(高さ約16,384px)を超える場合に警告し、書き出しボタンを無効化するよう修正

  • デバッグログ表示欄を追加(動画読み込み・抽出・書き出しの各段階をリアルタイム表示)
  • 動画データの読み込みに8秒のタイムアウトを追加し、非対応コーデック(iPhoneの.mov/HEVC等)の場合に分かりやすいエラーメッセージを表示するよう修正
  • フレームseek処理の不具合(先頭フレームで止まる問題)を修正
ver1
  • 動画のドラッグ&ドロップ読み込み

  • 出力サイズの事前計算表示
